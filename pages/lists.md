# Reactome-Recon lists

Reactome-Recon lists were generated automatically using a combination of two resources: the Reactome Neo4j graph database (Fabregat et al., 2018, PMID: 29377902) and the Human Metabolic Network Reconstruction Recon2 (Thiele et al., 2013, PMID: 23455439), combined in one Neo4j graph database.

### <a href="/reactome-recon-proteins/">Reactome-Recon List 1 - Proteins</a>
  
The list includes proteins that Recon2 lists as enzymes on their own.

### <a href="/reactome-recon-complexes/">Reactome-Recon List 2 - Complexes</a>

This list includes proteins that Recon2 lists as parts of enzyme complexes.
