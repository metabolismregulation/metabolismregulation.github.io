## Regulation Patterns page

/regulation-patterns/ (user, 2026-10-30; hidden like the Atlas: not in the navigation, no sitemap, noindex) collects
recurring regulation patterns of cell signalling with their sources' examples, and draws some as example maps. The
name leaves out "Atlas" while it lives on this site, as the Atlas is /atlas/.

The pattern list `_data/regulation_patterns.csv` and the example maps in `regulation-patterns/` (GraphML, SVG
drawn by yrender) are copies: the collection, its sources and the map builds are kept in a private repository,
whose copy script writes them here. Change them there and copy again, never here. The page text is edited here.

Example maps are cut from Atlas maps (the user's layouts kept) and finished with the layout skill. Each map's text
names its pattern, says what it shows with the source section, and links the maps it was cut from.
